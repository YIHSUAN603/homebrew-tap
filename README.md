# homebrew-tap

Homebrew tap for [Helm](https://github.com/YIHSUAN603/Helm) and
[Sage](https://github.com/YIHSUAN603/Sage).

```bash
brew tap YIHSUAN603/tap
```

Neither app is notarized by Apple, so both casks clear the quarantine flag in
`postflight` after installing — Homebrew 6 removed the `--no-quarantine` install
flag, so passing it now fails with `Error: invalid option`. The casks pin the
SHA-256 of every disk image they download.

## helm-terminal — a terminal that watches your AI coding agents

```bash
brew install --cask helm-terminal
```

- The cask is `helm-terminal`, not `helm`: homebrew/core has an unrelated `helm`
  formula (Kubernetes Helm).
- Helm updates itself, so the cask declares `auto_updates` and `brew upgrade`
  skips it. Use `brew upgrade --cask --greedy helm-terminal` if you would rather
  Homebrew did it.
- If macOS still says the app is damaged, run
  `xattr -cr /Applications/Helm.app` once.

Removing it:

```bash
brew uninstall --cask helm-terminal        # just the app
brew uninstall --cask --zap helm-terminal  # also its settings and caches
```

`--zap` deletes `~/Library/Application Support/com.arieschao.helm`, which is
where your `agents.json` lives. It does **not** touch `~/.claude/settings.json`:
if you installed Helm's agent integrations, remove the entries there whose
command mentions `HELM_EVENT_PORT` or `helm-statusline`, or Claude Code will
keep calling scripts that no longer exist.

`Casks/helm-terminal.rb` is generated by
[Helm's `update-homebrew-cask.yml`](https://github.com/YIHSUAN603/Helm/blob/main/.github/workflows/update-homebrew-cask.yml)
on every published release — edit the workflow, not the cask.

## sage — 桌面 AI 小夥伴

```bash
brew install --cask YIHSUAN603/tap/sage
```

- 必須使用完整名稱 `YIHSUAN603/tap/sage`：官方 homebrew-cask 已有同名的 `sage`
  （SageMath 數學軟體），只寫 `sage` 會裝錯。
- 若 macOS 仍顯示「已損毀，無法打開」，執行一次
  `xattr -cr /Applications/sage.app`。

更新與移除：

```bash
brew upgrade --cask YIHSUAN603/tap/sage
brew uninstall --cask sage        # 移除 App
brew uninstall --cask --zap sage  # 連同設定檔一併移除
```
